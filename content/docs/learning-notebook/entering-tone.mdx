## 基础操作

| 快捷键     | 功能     |
| ---------- | -------- |
| `G`        | 平移     |
| `S`        | 缩放     |
| `R`        | 旋转     |
| `A`        | 全选     |
| `X`        | 删除     |
| `Ctrl + A` | 应用变换 |
| `Ctrl + Z` | 撤销     |

- `G`、`S`、`R` 快捷键后面可以加上 `X`、`Y`、`Z` 来指定轴向，例如 `G + X` 表示沿 X 轴平移。
- `Ctrl + A` 应用变换后面可以加上 `S`、`R`、`L` 来指定应用的变换类型，例如 `Ctrl + A + S` 表示应用缩放变换。
- `Ctrl + A` 应用变换后面可以加上 `Shift` 来指定清除变换，例如 `Ctrl + A + Shift + S` 表示清除缩放变换。
- `Ctrl + Z` 撤销后面可以加上 `Shift` 来指定 redo，例如 `Ctrl + Z + Shift` 表示 redo。

## 添加物体

| 快捷键      | 功能     |
| ----------- | -------- |
| `Shift + A` | 添加物体 |

- `Shift + A` 快捷键后面可以加上 `Shift` 来指定添加的物体类型，例如 `Shift + A + Shift + C` 表示添加立方体。
- 物体类型包括：
  - `C` - 立方体
  - `U` - 圆柱体
  - `V` - 圆锥体
  - `S` - 球体
  - `G` - 圆环
  - `M` - 长方体
  - `L` - 圆台
  - `K` - 超级立方体

## 其他

| 快捷键     | 功能         |
| ---------- | ------------ |
| `H`        | 隐藏选中物体 |
| `Alt + H`  | 显示隐藏物体 |
| `Ctrl + N` | 重置视图     |

- `H` 隐藏选中物体后面可以加上 `Shift` 来指定隐藏所有物体，例如 `H + Shift` 表示隐藏所有物体。
- `Alt + H` 显示隐藏物体后面可以加上 `Shift` 来指定显示所有物体，例如 `Alt + H + Shift` 表示显示所有物体。
- `Ctrl + N` 重置视图后面可以加上 `X`、`Y`、`Z` 来指定重置的视图方向，例如 `Ctrl + N + X` 表示重置为 X 轴方向的视图。

| 快捷键      | 英文名称   |
| ----------- | ---------- |

| `Ctrl + Z`  | Undo       |
