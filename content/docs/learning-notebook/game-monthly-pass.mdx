## 月卡的核心价值

<Callout type="info" title="💡 双重价值">
月卡解决了游戏运营的两个核心问题：

1. **付费转化** - 30 元价格精准瞄准中小 R 付费群体的心理承受阈值
2. **留存活跃** - 损失厌恶心理驱动玩家每日登录领取奖励

</Callout>

<Callout type="warn" title="⚠️ 核心前提">
**留存和活跃是实现游戏付费转化的基本前提！**

玩家以月为单位购买月卡，能够养成良好的付费习惯，稳定游戏收入基本盘。

</Callout>

---

## 月卡与通行证的区别

| 特性         | 通行证               | 月卡            |
| ------------ | -------------------- | --------------- |
| **周期**     | 以赛季（版本）为单位 | 按月订阅        |
| **获取方式** | 完成任务提升等级     | 直接领取        |
| **核心机制** | 任务驱动             | 订阅制服务      |
| **奖励形式** | 等级奖励             | 每日奖励 + 权益 |

### 各类型月卡详解

<Accordions>
<Accordion title="💎 资源型月卡详细说明">

**本质：** 卖数值，通过资源的高回报直接推动玩家数值成长

**特点：**

- 月卡提供的资源直接作用于玩家的属性、装备、战力、等级等核心数值系统
- 购买后会立即返还等价资源
- 每日上线赠送一定奖励

**优势：** 能够促进玩家长期活跃和长期留存，已被业内广泛采用

</Accordion>

<Accordion title="👑 权益型月卡详细说明">

**本质：** 通过售卖游戏内特权来提高玩家游戏体验

**常见特权：**

- 一键扫荡、自动打怪
- 特殊道具购买权
- 特殊称号、进场动画
- 防踢权等

**价值：**

- 提高游玩乐趣
- 满足玩家的虚荣心

**组合方式：** 权益型月卡和资源型月卡在游戏中既可单独出现，也可组合存在

</Accordion>

<Accordion title="⏰ 时间型月卡详细说明">

**本质：** 收费模式类似买断制，但按月付费

**特点：**

- 常见于 MMORPG 游戏中
- 玩家在免费游玩时间结束后，需要持续购买月卡才能继续游玩
- 游戏一般允许玩家无限次参与团队副本、大秘境、PVP 等社交玩法

**✅ 优点：**

- 只要有稳定的玩家数量，就能为游戏提供持续收入
- 支撑持续内容更新

**❌ 缺点：**

1. **付费门槛较高** - 会阻碍新玩家尝试游戏
2. **玩家付费心态改变** - 更倾向于玩免费加氪金游戏
3. **必须物有所值** - 才能留住玩家

</Accordion>
</Accordions>

## 资源型月卡的设计

要想做好资源型月卡的设计，离不开下面三个方面：

<Steps>
<Step>

### 💰 月卡价格定位

**定价区间：** 20-40 元

**最佳价格：** 30 元

- ✅ 换算为 **1 元/天**，玩家易于计算
- ✅ 加深月卡价格低廉的印象
- ✅ 促进玩家付费意愿
- ✅ 与首充优惠价格拉开差距，避免价位重合

> 💡 **设计原则**
>
> 为了让多数用户都有付费，价格不会太高。30 元这个价格点既能覆盖中小 R 付费群体，又便于玩家心理计算。

</Step>

<Step>

### 🎁 付费后立即返还多少奖励

<Callout type="info" title="人性洞察">
  人性是短视的，玩家即使知道月卡的整体价值，也会更关注**当前付费后的即时反馈**，会衡量当天购买后获得的价值。
</Callout>

**设计原则：**

- 立即返还价值等同于商店直接购买的资源
- 提供正向的、物超所值的体验
- 强化首次付费的满足感

**重要性：** 一个正向的、让玩家感觉物超所值的体验至关重要！

</Step>

<Step>

### 📊 付费后每日赠送多少奖励

**核心公式：**

```
次日赠送奖励 / 首日返还奖励 > 1/5
```

**实际案例：**

```
首日返还：300 钻石
次日最低：60 钻石（300 × 1/5）
建议范围：60-100 钻石
```

**设计考量：**

<Accordions>
<Accordion title="📈 心理学因素">

- 对玩家来说，月卡前期获得奖励的感受要比后期更加明显
- 如果首日获得的奖励与第二日奖励差距过大，会造成玩家较强的心理落差
- 从而影响后续的付费与活跃

</Accordion>

<Accordion title="⚖️ 平衡性考量">

**资源产出平衡：**

- 与不同游戏资源各个途径产出的比例设计有较大关联

**避免通货膨胀：**

- 时间越长，玩家积累的奖励越多
- 设定过多奖励会影响游戏内的价值体系
- 也会影响游戏后续的活动卡池流水

**结论：** 每日奖励金额不能太高，需要精心平衡

</Accordion>
</Accordions>

</Step>
</Steps>

## 改进的月卡设计

<Callout title="💡 参考案例：卡拉彼丘">
**创新点：**
- 提供**两种月卡类型**供玩家选择
- 可保留 **3 天未登录**领取的奖励
- 降低玩家因偶尔缺席而产生的损失感
- 提高月卡的用户友好度

**启示：** 在传统月卡基础上增加容错机制，能够提升玩家体验和付费意愿

</Callout>
