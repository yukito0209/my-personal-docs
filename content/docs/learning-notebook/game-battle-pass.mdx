## 通行证的核心概念

<Callout type="info" title="💡 什么是通行证？">
**游戏通行证（Battle Pass）** 是一种将玩家游戏行为与奖励进度相捆绑的盈利模式。

通过完成任务、积累经验来提升通行证等级，解锁对应的游戏奖励。通常分为**免费通行证**和**付费通行证**两条（或三条）并行的奖励轨道。

</Callout>

<Callout type="warn" title="⚠️ 核心机制">
**任务驱动 + 等级解锁 + 限时周期 = 持续参与动力**

通行证通过赛季制（通常 30-45 天）营造紧迫感，驱动玩家持续登录和完成任务，实现留存与付费的双重目标。

</Callout>

---

## 通行证与月卡的对比

| 特性         | 通行证 Battle Pass            | 月卡 Monthly Card   |
| ------------ | ----------------------------- | ------------------- |
| **周期**     | 以赛季/版本为单位（30-45 天） | 按月订阅（30 天）   |
| **获取方式** | 完成任务提升等级              | 每日登录直接领取    |
| **核心机制** | 任务驱动 + 等级解锁           | 订阅制服务          |
| **奖励形式** | 等级奖励（阶梯式）            | 每日固定奖励 + 权益 |
| **参与门槛** | 需要完成任务（肝）            | 只需登录（轻度）    |
| **价值感**   | 成就感 + 丰富奖励             | 高性价比 + 稳定收益 |
| **付费压力** | 中等（怕浪费已购买的）        | 低（习惯性续费）    |

<Callout type="success" title="✨ 互补关系">
**月卡 + 通行证** 是目前手游商业化的黄金组合：

- **月卡**：低门槛、高性价比，吸引中小 R 玩家建立付费习惯
- **通行证**：中等价位、丰富奖励，提供成就感和持续参与动力

两者结合可以覆盖不同付费意愿的玩家群体，最大化收入。

</Callout>

## 通行证的分类

<Cards>
  <Card title="🆓 免费通行证">
    **核心：** 所有玩家都能获得的基础奖励

    - 提供基础资源和道具
    - 奖励价值相对较低
    - 作为付费通行证的对比参照

    💡 **作用：** 让玩家体验通行证机制，刺激付费欲望

  </Card>

  <Card title="💎 付费通行证">
    **核心：** 购买后解锁的高价值奖励轨道

    - 奖励数量和质量远超免费版
    - 通常包含独占皮肤、角色等
    - 价格一般在 68-128 元之间

    ✅ **主要收入来源**

  </Card>

  <Card title="⭐ 高级通行证">
    **核心：** 付费通行证的升级版

    - 直接赠送 10-20 级经验
    - 额外奖励或专属道具
    - 价格通常是普通版的 1.5-2 倍

    🎯 **面向重度玩家和时间不足的付费用户**

  </Card>
</Cards>

## 通行证的设计要素

<Steps>
<Step>

### 📊 等级与经验系统

**设计原则：**

- **总等级数：** 通常设置 50-100 级
- **经验获取：** 日常任务 + 周常任务 + 赛季任务
- **升级曲线：** 前期快速升级（正反馈），后期放缓（延长游玩时间）

<Callout type="info" title="💡 经验设计技巧">
**每日任务经验 ≈ 总经验的 60-70%**

确保正常游玩的玩家能在赛季结束前满级，避免"买了也完不成"的负面体验。

</Callout>

</Step>

<Step>

### 🎁 奖励分配策略

**免费 vs 付费奖励对比：**

| 等级区间 | 免费奖励         | 付费奖励                 |
| -------- | ---------------- | ------------------------ |
| 1-10 级  | 少量基础资源     | 中等资源 + 小型道具      |
| 11-30 级 | 基础道具         | 大量资源 + 稀有道具      |
| 31-50 级 | 稀有资源（少量） | 独占皮肤/角色 + 海量资源 |
| 50+ 级   | 象征性奖励       | 顶级奖励（光效、称号等） |

**关键奖励放置：**

- **第 1 级：** 立即给予小奖励（即时满足）
- **第 10-15 级：** 放置吸引人的奖励（刺激购买）
- **第 30 级：** 中期高潮奖励（维持动力）
- **满级：** 终极奖励（完成目标的成就感）

</Step>

<Step>

### ⏰ 时间与周期设计

**赛季周期：** 30-45 天

- **太短：** 玩家压力大，容易疲劳
- **太长：** 失去紧迫感，中途流失

**任务刷新机制：**

- **日常任务：** 每日刷新，提供稳定经验
- **周常任务：** 每周刷新，奖励更丰厚
- **赛季任务：** 整个赛季有效，提供大量经验

<Callout type="warn" title="⚠️ 防止玩家疲劳">
**设计补偿机制：**

- 允许补做前几天的日常任务
- 后期提供经验加成活动
- 赛季末期开放经验购买（付费加速）

</Callout>

</Step>
</Steps>

## 通行证设计的心理学原理

<Accordions>
<Accordion title="🎯 沉没成本效应">

**原理：** 玩家购买通行证后，为了"不浪费"已支付的费用，会更积极地完成任务。

**应用：**

- 购买后立即给予部分奖励（强化购买决策）
- 显示"已获得价值"和"剩余可获得价值"
- 在赛季中期推送"您已完成 XX%"的提醒

**案例：** 原神的纪行系统会显示"本期纪行已获得价值 XXX 原石"

</Accordion>

<Accordion title="📈 进度可视化">

**原理：** 清晰的进度条和等级显示能给玩家明确的目标感和成就感。

**设计要点：**

- 醒目的进度条（主界面可见）
- 每次升级都有视觉和音效反馈
- 显示"距离下一个大奖还需 X 级"

**心理效应：** 蔡格尼克效应（未完成的任务更容易被记住）

</Accordion>

<Accordion title="💰 锚定效应">

**原理：** 通过对比免费和付费奖励，让玩家感知到付费版的"超值"。

**设计技巧：**

- 在同一等级同时展示免费和付费奖励
- 付费奖励的视觉效果更华丽（金色边框、特效）
- 计算并展示"总价值"（如：价值 6000 原石的奖励，仅需 68 元）

**参考：** 崩坏星穹铁道的"星芒兑换"会显示所有奖励的总价值

</Accordion>

<Accordion title="⏳ 稀缺性与限时性">

**原理：** 限时赛季制造紧迫感，促使玩家尽快购买和完成。

**应用：**

- 赛季结束后奖励永久消失
- 独占皮肤/角色不会复刻（或很久后才复刻）
- 倒计时提醒（"距离赛季结束还有 X 天"）

**效果：** FOMO（Fear of Missing Out，错失恐惧症）驱动购买

</Accordion>
</Accordions>

## 通行证设计的最佳实践

<Callout type="success" title="✅ 成功要素">
**1. 高性价比**

- 奖励总价值应为售价的 **8-10 倍**
- 包含独占内容（皮肤、角色、武器等）

**2. 合理的完成难度**

- 正常游玩能在赛季内满级（完成度 80-90%）
- 提供补偿机制（经验加成、补做任务）

**3. 清晰的进度反馈**

- 醒目的进度条和等级显示
- 每次升级都有明确的奖励预览

**4. 灵活的奖励设计**

- 提供自选奖励（如星穹铁道的光锥自选）
- 兼顾不同玩家的需求（PVE、PVP、收集党）

**5. 合理的定价策略**

- 普通版定价在 68-98 元（一顿饭钱）
- 高级版提供明确的额外价值（省时间）

</Callout>

<Callout type="error" title="❌ 常见陷阱">
**1. 完成难度过高**

- 需要每天肝 3-4 小时才能满级 → 玩家疲劳、弃坑

**2. 奖励价值不足**

- 性价比低于直接购买 → 玩家不买账

**3. 强制付费感**

- 免费奖励过于寒酸 → 引发玩家反感

**4. 赛季周期不合理**

- 太短：玩家压力大
- 太长：失去紧迫感

**5. 缺乏补偿机制**

- 玩家因事耽误几天就无法满级 → 负面体验

</Callout>

## 关键要点总结

<Cards>
  <Card title="🎯 核心机制">
    **任务驱动 + 等级解锁 + 限时周期**

    通过赛季制和任务系统，持续驱动玩家参与，实现留存与付费的双重目标。

  </Card>

  <Card title="💰 商业价值">
    **中等价位 + 高性价比 + 独占奖励**

    通行证是月卡之后的第二大稳定收入来源，覆盖中小 R 和中 R 玩家群体。

  </Card>

  <Card title="🧠 心理学应用">
    **沉没成本 + 进度可视化 + 稀缺性**

    利用多种心理学原理，提高玩家的参与度和付费意愿。

  </Card>

  <Card title="⚖️ 平衡设计">
    **奖励价值 vs 完成难度**

    确保玩家"买得起、玩得动、拿得到"，避免负面体验。

  </Card>
</Cards>
